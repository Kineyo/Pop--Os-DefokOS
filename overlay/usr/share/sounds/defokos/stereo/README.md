# DefokOS Sound Scheme (Stereo)

Coloca aquí los archivos de sonido en formato `.oga` u `.ogg` correspondientes a la especificación Freedesktop Sound Theme Spec:

- `bell.ogg` (Campana o alerta de terminal)
- `dialog-information.ogg` (Notificaciones del sistema)
- `dialog-warning.ogg` (Advertencias)
- `dialog-error.ogg` (Errores)
- `message-new-instant.ogg` (Mensajes entrantes / chat)
- `audio-volume-change.ogg` (Ajuste de volumen)
- `desktop-login.ogg` (Inicio de sesión / bienvenida)
- `desktop-logout.ogg` (Cierre de sesión)

Los archivos heredan automáticamente de los sonidos por defecto del sistema (`freedesktop`) si no se especifican.
